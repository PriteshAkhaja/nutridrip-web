NutriDrip Design System · v0.1 · Block 0

Everything here is a level between empty and full.

One primitive — the Fill — carries the whole product: a patient's vitality, sixteen nutrient risks, how much of an IV bag has run, how much of a batch remains, how far a nurse has gone through a twenty-nine step checklist. It never decorates. It always encodes a real quantity. Alongside it, one rule: clinical data is monospaced, prose is not.

01

Colour

Warm paper, eucalyptus primary, apricot reserved for vitality. The four clinical hues are a controlled vocabulary — they appear only when something is genuinely safe, cautionary, critical or informational, and never without a word or mark beside them.

{{ group.name }} {{ group.note }}
{{ s.name }} {{ s.hex }} {{ s.use }}
Do

Pair every colour with a word. SpO₂ 91% reads as critical because it says Below safe range, not because it is red.

Don't

Never tint a card green because it is pleasant, or amber because it is a promotion. Clinical hues are reserved. Decoration uses paper, line and primary only.
